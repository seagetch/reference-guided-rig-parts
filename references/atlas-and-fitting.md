# 初期切り出し、参照アトラス、再作成、合わせ込み

## 元画像から初期パーツを切り出す

新規分割では、最初に元画像の画素から初期パーツを作り、その後に画像生成で再作成・補修する。切り出しが、元の配置・縮尺・輪郭・色・描線・意匠を保持した編集入力になる。既存PSD／RGBAパーツがある場合はそれを用い、不足部品だけ元画像から切り出す。

1. 元キャンバスと座標系を固定し、部品ごとに見えている領域をマスクで指定する。初期アルファは `元アルファ × 所有マスク / 255` とし、元アルファを所有マスクで置換しない。透明領域の残留RGBや半透明の縁を不透明化しない。抽出処理は利用中の画像ツールの制約に従う。
2. 元位置を保持したRGBA、またはトリミングしたRGBAと復元用のオフセットを保存する。部品ID、元画像、マスク／抽出範囲、元座標、重なり順を台帳に残す。白髪・白目・レース等を背景色と一緒に消さない。
3. 部品一覧と元位置での初期合成を作り、切り出し漏れ、混入、位置ずれを確認する。見える範囲が元絵に合うことと、動かせる部品として成立することを別に評価する。
4. 切り出しだけでは得られない隠れ面・根元・接合の延長、および誤って分断した面や混入箇所を、再作成対象として記録する。初期パーツを保存したうえで、次節のシートに元絵と並べて画像生成へ渡す。

再作成では、この初期パーツと元絵の両方を参照し、見える意匠を保ちながら部品単位の連続面へ描き直す。切り出し境界を最終形状として固定せず、必要な隠れ面を補い、他部品の絵を取り除く。十分に成立している部品は保持し、修復が必要な部品を再作成する。

[cutout事例](casebook.md#cutout) → [atlas事例](casebook.md#atlas) の順に、初期パーツから再作成用の入力へ進む流れを確認する。

## 準備と座標

各部品にID、自然言語名、所有する面、混入禁止の要素、前後関係、接合先、見える範囲、補完範囲を定義する。断片の境界は意味的な部品境界とは限らない。

アトラスは左に部品名＋既存画、右に元絵。部品は重ねず補完用の余白を置き、ラベルを絵に被せない。[案件の倍率制約](task-contract.md)を守り、小部品をセルいっぱいに拡大しない。縮尺禁止時は全身・局所とも原寸の切り出しを併記する。検査用の拡大表示を生成入力に混ぜない。

部品台帳には、元キャンバス寸法、元絵識別子、source_box、atlas_box、scale、抽出範囲、元位置に戻す変換、alpha仕様、clip_to、接合アンカーを記録する。可視断片の矩形と補完予定領域を区別し、抽出範囲は補完領域全体を含める。小さな固定余白で新しい首や手首を切り落とさない。矩形の座標原点・端・単位を明記する。シート寸法だけでなく各セル内の配置・可視幅も確認し、生成が変更した座標で元のセル切り出しを盲目的に使わない。

例として [atlas事例](casebook.md#atlas) を開く。初期シートの断片や不透明背景は修復前の状態であり、完成仕様ではない。

## 参照のアルファと背景

元画像のアルファ分布、透明画素内のRGB、白／暗背景での縁を調べる。元RGBAを直接RGBへ変換してから貼ると、透明だった背景色が復活する。指定背景へ `alpha_composite` 等で正しく合成してから表示用RGBにする。右側の元絵も同じ処理を使い、実際のシートを生成前に開く。

元アルファが使えるならそれを活用し、不備がある領域だけを修復対象にする。単に最大値が255未満だからという理由で全アルファを正規化しない。生成された背景除去画像のRGBへ元絵を置き換えない。ゼロアルファのRGBをゼロにしても、半透明境界の背景混入や別部品の混入まで直ったことにはならない。

Pillowが利用できる場合は、任意の補助ツール `scripts/reference_rgba.py` を使える。自動生成や意味的なマスク選択は行わず、元画素尺度を保持する。初期切り出し用であり、隠れ面を補完した最終パーツへ元アルファを再適用しない。

```sh
python3 scripts/reference_rgba.py inspect source.png
python3 scripts/reference_rgba.py compose source.png reference-white.png --background '#ffffff'
python3 scripts/reference_rgba.py cutout source.png ownership-mask.png initial-part.png
```

所有マスクは同寸法のLまたは1モード。ツールは元ファイルの上書き、既存出力の上書き、寸法不一致を拒否し、ハッシュとアルファ情報を標準出力へ返す。出力を見てから採用する。マスクの意味・絵の品質は検査しない。

## バッチの単位

両目と顔参照、肩と両腕、袖と袖口、耳前後の髪など関係を一緒に直す部品をまとめる。個別に作るほど整合性が落ちる一方、全部品を巨大シートに詰めて解像度が足りなくなるのも避ける。ラベルではなく画像の意味を見て一括修復できる粒度にする。

## 生成への指示契約

次を具体的な対象部品に置き換える。

```text
目的：既存リグパーツの修復。新しいキャラクターのデザインではない。
入力：Aは編集対象、Bは同座標の再合成、Cは元絵の最上位参照。
対象：どのセル／部品を修復し、どこは変更しないか。
誤り：元絵との差、欠損、混入、接合の問題を箇所ごとに記す。
保持：元絵で見える輪郭と配置、非対称性、描線、意匠、良い接合点。保持領域を示す。
補完：指定した隠れ領域へ連続面・根元を原寸で延長する。可視断片の外接矩形は拡張してよい。下の別部品は描かない。
出力：指定セル・倍率・フレームを維持した独立RGBA部品。
除外：偽市松、白台紙、肌の背板、他部品の残骸、ラベルの描き込み。
```

元絵パネルを生成が変更しても、それを元絵や製品へ採用しない。生成したシートは指示の遵守を検査してから抽出する。隠れ面は推定補完として区別する。

隠れ面の延長が必要な依頼に「部品を大きくするな」「元の外枠を変えるな」「内部の穴だけ埋めろ」を一律に付けない。尺度の固定を、可視断片の欠けた輪郭の固定へ置き換えない。首などの必要な部位が入力にほぼ残っていなければ、ラベルだけで復元を期待せず、元絵と補完領域・接合先を明示する。

本物のアルファを要求・検査する。白髪や白目を一律の白閾値で消さない。別部品を透かす穴に肌色を塗って代用しない。RGBAの存在だけでは、絵に市松模様が焼き込まれていない証明にならない。

## 変形と統合

許可された変換の範囲で、まず並進、必要なら縮尺・縦横比・回転・せん断、最後に最小限の滑らかな局所変形を検討する。縮尺・リサンプリング禁止なら補間を伴う変形も使わず、整数並進または原寸での再修復へ戻る。関連部品を一緒に照合し、虹彩だけ合っていても両目の間隔が異なれば不合格。

良い肩・手首・指先・髪の根元等をアンカーにする。変形で折り返し、極端な伸縮、不自然なくびれ、髪の太りが生じたら採用しない。絵そのものの意味・形が悪ければ生成修復へ戻る。固定の最大変形率を普遍の正解にしない。

画像処理を行う際は利用中の画像ツールの制約に従う。許可された幾何・合成処理では、アルファを考慮した補間で黒／白フリンジを防ぎ、元の高品質候補から変換を適用して反復再サンプリングを避ける。単純な半透明重ねで異なる輪郭を二重にしない。画像生成の代わりに手続き的な描画で欠損を捏造しない。

元画素を候補へ戻す場合も、その部品が所有すると確認できた範囲に限定する。大まかな矩形・肌色条件・元マスクを「忠実度保持」として再適用し、除去済みの影・眉・布を戻さない。元の可視画素を保つ検査と、隣の可視部品へ侵入しない検査を対にする。

位置・形状の差は合わせ込み、別部品混入は意味の修復、前後の誤りは構造、矩形影はPSD表現へ戻す。各試行で「差→原因→変更対象→結果→採否」を記録する。
