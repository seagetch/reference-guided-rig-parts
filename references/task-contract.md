# 制約・入力・版の管理

開始時に既知のユーザー指定から記録する。既に指定された制約や許可を再質問しない。推定で置く項目は推定と示し、必要な判断だけを確認する。

## 案件の制約

| 項目 | 記録する内容 |
| --- | --- |
| 基準 | 元絵のパス・SHA-256・寸法、作業開始版、ユーザーが指定した基準版 |
| 座標 | 原点、矩形の端の扱い、L/Rが画面側かキャラクター側か、双方の対応 |
| 変換 | 素材と生成参照それぞれの倍率、許可する並進・変形、禁止されたリサンプリング |
| 範囲 | 修正部品、保持すべき可視画素・接合、既知の未解決箇所、補完予定領域 |
| 部品構造 | 顔・首等の独立可動単位、各部品が所有／除外する絵、前後ペア、影の受け面 |
| 検証 | 隠す遮蔽物、必要な移動・露出、保存形式、対象アプリで確認できる範囲 |

既定は元の画素尺度を使う。別倍率は依頼で許可される範囲でのみ使い、元座標へ戻す変換と品質への影響を記録する。案件に縮尺・リサンプリング禁止があれば、事例の拡大図や合わせ込み手順から例外を推論しない。

次の四つを混同しない。

- 素材を拡大縮小すること。
- 生成へ渡す参照シートを拡大縮小すること。
- 閲覧だけの拡大表示。許される場合に限り、検査用と明示して素材・生成入力へ流用しない。アプリの表示ズームと保存画素寸法も別。
- 同じ座標系で隠れ面を追加すること。部品の外接矩形が広がっても縮尺変更ではない。見える輪郭の保持領域と、追加してよい隠れ領域を別に指定する。

キャンバス寸法や `scale: 1` の記録だけでは、生成された部品内部の倍率・形状が維持された証拠にならない。可視の幅・位置・アンカーも元絵と照合する。

## 画像の役割

| 種類 | 用途・保持条件 |
| --- | --- |
| 元RGBA | 見える意匠の根拠。ファイルを変更せず、RGBだけでなく元アルファも調べる |
| 表示用参照 | 元RGBAを指定背景へアルファ合成した派生物。生成された右パネルを元絵の代わりにしない |
| 初期切り出し | 元アルファ×所有マスク。可視の断片であり、完成した隠れ面ではない |
| 生成候補 | 未採用。可視部の忠実度と隠れ面を別に検査し、元画像の代替基準にしない |
| 作業版 | 内部で選択した部品と台帳から作る編集マスター。ユーザー承認済みとは限らない |
| 検査画像 | 比較・露出・独立再合成の出力。対象部品を変更せず、対象版へ結び付ける |

右側の参照背景、部品内部の背景混入、表示ソフトの透過表示は異なる問題である。指摘された実際のシート／部品を開き、どの段階で背景が現れたか調べる。入力が壊れていれば下流の描き直しより先に入力作成処理を直す。

## 版・採否・依存関係

元絵、参照シート、生成入力・指示、候補、選択部品、台帳、PSD、検査結果を対応付ける。実際に使ったスキルの版または参照文書のハッシュも残す。自動検査は対象PSD・部品・台帳のハッシュを記録し、別版の成功結果を現行版へ流用しない。

状態は少なくとも「未検査候補」「内部選択した作業版」「ユーザー不採用」「ユーザー承認済み」を区別する。沈黙や新しい指摘を承認へ読み替えない。内部選択のたびにユーザーの追加承認を要求する規則ではない。

不正な参照や抽出処理が見つかったら、その入力に依存した候補を再検査対象に戻す。棄却理由と、それを次回どの入力・指示・処理で変更するかを記録する。同じ入力と指示のまま生成を繰り返さない。保護対象にも既知の未達があれば未達として持ち越す。

検査スクリプトは部品、マスク、候補選択、PSDを変更しない。修正が必要なら修正工程へ戻し、新しい版を保存してから検査する。同じ成果物への書き込みや相互に依存する処理を並列実行せず、生成・補修→組み込み→保存完了→読み戻し→比較公開の依存順を守る。終了していない書き出しのファイルや前回のプレビューで採否を決めない。

旧スクリプトを再実行する前に、棄却済みの候補や過去のマスクを再導入しないか確認する。現行部品の選択元を一つに定め、履歴用記録を「今回」「現在」の検証として扱わない。
