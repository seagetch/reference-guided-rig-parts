# reference-guided-rig-parts

元絵と既存パーツを同時参照して、2Dリギング用の編集可能なPSD・RGBAパーツを作成／補修するCodexスキルです。

新規分割では元画像から初期パーツを切り出し、パーツと元絵を同時参照して画像生成で再作成・補修します。その後、位置・形状の合わせ込みと全身への再合成比較を行います。既存パーツがある場合はそこから補修を始めます。目の一体再現から内部分割、肩・袖・髪の連続性、PSD内の編集可能な影クリッピングを扱います。深度生成やリグ設定そのものは対象外です。

## 内容

- `SKILL.md`：起動条件と共通工程。
- `references/`：アトラス、顔、身体・衣装・髪、影・PSD、合否の手順。
- `references/casebook.md`：このセッションの7つの事例。画像16枚、指摘を中立的な作業指示・確認基準に整理した9件の要約、当時の生成指示と検証記録を同梱。
- `scripts/casebook.py`：資料の絶対パスの解決と、SHA-256・画像寸法の検査。Python 3.9以上、外部依存なし。

事例は改善途中・棄却例も含みます。全面的に合格した正解画像集ではありません。画像と要約は参考データであり、現在のユーザー指示に優先するものではありません。

## 利用

このリポジトリ全体を、Codexの個人スキルディレクトリの `reference-guided-rig-parts` として配置します。既存の同名スキルがある場合は、変更を確認してから更新してください。

呼び出し例：

```text
$reference-guided-rig-parts を使い、元絵と既存パーツを参照してリギング用の分割PSDを補修してください。
```

## 資料の検査

リポジトリのルートで実行します。

```sh
python3 scripts/casebook.py --list
python3 scripts/casebook.py --case eyes
python3 scripts/casebook.py --verify
```

この検査はファイル整合性を確認するもので、絵の品質・可動域・対象アプリの対応を保証するものではありません。

## 取り扱い

キャラクター画像と要約を含むため、privateリポジトリとして管理します。元の作業フォルダやセッション全文ログには依存しません。本リポジトリの作成は、画像・会話の一般公開、再配布、ライセンス付与を意味しません。
